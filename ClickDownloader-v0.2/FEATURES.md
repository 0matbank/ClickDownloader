# Feature status

## Ready in v0.2
- Multi-URL queue
- Quality presets
- Audio extraction
- FFmpeg merge
- aria2
- Background progress
- Wi-Fi-only
- Retry/cancel
- Persistent history
- cookies.txt private import
- filename template
- subtitle and SponsorBlock toggles
- SAF folder permission picker

## Prepared but not fully wired
- Custom SAF output: permission is saved, final media export is not yet copied to that URI.
- Raw format picker: current build uses resilient quality presets rather than exposing extractor rows.
- Playlist expansion: paste multiple URLs works; automatic playlist item expansion UI is not implemented.

## Intentionally excluded
- DRM decryption
- paywall bypass
- silent APK self-update/install
- accessibility service
- broad storage permission
